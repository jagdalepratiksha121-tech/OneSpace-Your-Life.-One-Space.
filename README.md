# OneSpace – Personal Life Operating System

**OneSpace** is an all-in-one personal life management platform designed to help students, working professionals, and individuals organize their daily activities, manage finances, track goals, and store important information in one place.

Instead of using multiple applications for different purposes, OneSpace brings essential daily management tools together in a single, organized platform.

## 🚀 Project Overview

Managing daily tasks, personal finances, goals, schedules, and important documents across multiple applications can be difficult.

OneSpace aims to solve this problem by providing a centralized platform where users can manage their personal and professional lives efficiently.

## ✨ Key Features

### 1. 📋 Task Management
- Create and manage daily tasks.
- Organize tasks and schedules.
- Track task completion and performance.
- View task progress through graphs.

### 2. 🎯 Goals & Progress Tracking
- Set personal and professional goals.
- Track daily progress.
- Monitor achievements and performance.
- Visualize goal progress through charts.

### 3. 💰 Personal Finance Management
- Record daily income and expenses.
- Manage budgets and savings.
- Track money given to others and money to receive.
- Set reminders for pending payments.
- View financial reports and graphs.

### 4. 📝 Notes & Information Manager
- Save important notes and personal information.
- Organize saved information in one place.
- Access important details whenever needed.

### 5. 📁 Smart Document Storage
- Upload and store PDF, Word, and other important files.
- Save documents with date and time.
- Easily search and access previously saved documents.
- Keep important files organized in one place.

### 6. 🔗 Important Links Manager
- Save useful website links.
- Organize important URLs for quick access.

### 7. ⏱️ Wellness & Activity Tracking
- Track sleeping hours.
- Monitor study time.
- Track phone usage.
- Maintain daily activity records.

### 8. 📊 Progress Analytics
- Separate progress graphs for tasks, goals, finances, and savings.
- View daily and historical performance.
- Understand personal progress through visual analytics.

### 9. 👤 User Profile & Authentication
- Secure user login and registration.
- Personalized user profiles.
- Individual user data management.
- Access the dashboard after successful login.
